# Amnezia Panel — Stage 2: Web UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One single-page web app on the Stage 1 REST API, with a user cabinet (spec items Б.1–Б.4) and an admin area (spec items А.1–А.7, server management).

**Architecture:** React + TypeScript SPA built by Vite into `panel/web/dist`. Caddy serves the build and proxies `/api`.
- Auth is the backend's HttpOnly cookie. Every unsafe request sends the `X-CSRF-Token` header, whose value is read from the `panel_csrf` cookie.
- Server state is managed by TanStack Query. The API types are generated from the backend's OpenAPI schema.
- Two areas: `/` (user) and `/admin` (admin). Each area has its own login page and a route guard based on `GET /api/auth/session`.

**Tech Stack:**
- Vite 8, React 19, TypeScript 5, React Router 7, TanStack Query 5, Mantine 9 (+ dates, notifications, modals), Recharts, react-i18next (ru default, en), @zxcvbn-ts/core.
- Tests: Vitest with Testing Library and MSW; Playwright for end-to-end runs against the real backend with an in-memory fake VPN server.

**Spec:** `docs/superpowers/specs/2026-09-26-amnezia-panel-design.md` (§9)

## Global Constraints

- The UI language defaults to `ru`, with `en` as the alternative. A language switch is shown in the header. All strings go through i18n; there is no hardcoded UI text.
- Error codes from the API (`{code, message}`) map to translated messages (`errors.<code>`). Unknown codes show `message`.
- A password must be at least 12 characters with a zxcvbn score of at least 3 (the server enforces the same rule). The indicator shows these requirements before the form is submitted.
- An invite key is shown once after user creation, with a copy button and a warning that it cannot be shown again.
- Delete and block actions ask for confirmation. Long-running server jobs show their progress by polling `GET /api/jobs/{id}`.
- Layout must work at phone width (360 px).
- No secrets live in localStorage. The only thing stored there is the language choice.
- `vpn_key`, `native` and `qr_svg` come from the backend. `qr_svg` is backend-generated SVG, rendered with `dangerouslySetInnerHTML` only after checking that it starts with `<svg`.

## Review Focus

1. **Session expired mid-use (401).** The app redirects to the right login page (user or admin) and keeps the target path. Tested in Task 2.
2. **Config creation fails with 503 or 409.** A readable, translated error appears, and the list is not changed. Tested in Task 5.
3. **Blocked or expired user opens the dashboard.** The status banner is visible, and the create, show and unblock actions are disabled or explained, with no crash on 403. Tested in Task 5.
4. **Invite key typed with spaces or lowercase.** It is accepted, because the server normalizes keys. Tested in Task 4.
5. **Admin closes the invite dialog.** The key cannot be retrieved again; the dialog says so. Tested in Task 6.

### Task 2: API client, session, i18n, routing

**Files:** `src/api/client.ts`, `src/api/client.test.ts`, `src/auth/session.tsx`, `src/auth/session.test.tsx`, `src/i18n/*`, `src/routes.tsx`, `src/components/AppLayout.tsx`, `src/components/ErrorAlert.tsx`

**Interfaces:**
- `api<T>(path, {method, body}) : Promise<T>`:
  - throws `ApiError {status, code, message}`;
  - adds `X-CSRF-Token` from the `panel_csrf` cookie on unsafe methods;
  - uses `credentials: "same-origin"`;
  - returns `null` on 204.
- `useSession() -> {role, id, login} | null`, plus `RequireRole role="user"|"admin"`, which redirects to `/login?next=` or `/admin/login?next=`.
- `errorText(t, err)` maps `ApiError.code` to the `errors.<code>` translation.

Steps:

- [ ] Write the failing tests:
  - the client sends the CSRF header on POST and not on GET;
  - it parses `{code, message}` into `ApiError`;
  - on 401 it calls the `onUnauthorized` hook;
  - `RequireRole` redirects to `/login?next=/` when the session is missing (MSW returns 401).
- [ ] Run them and watch them fail. Implement. Run them and watch them pass.
- [ ] Commit: `feat(panel-web): api client, session, i18n`.
